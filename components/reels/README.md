# reels/

> L2 | 父级: ../../README.md

正文里那台会动的图。它不是首屏那台机器的复制品（那台在 `../window/`，
几何逐项抄真组件）——这台是**示意图**：只保留能把一句话说完的那几笔，
其余一律骨架条。判据是：**这一节要讲的话，能不能由这个动作本身说出口。**

Apps 一节原来那台幻灯（`apps-reel.tsx`）已经退场：那一节改成一次演一只 App 的
真机，四只表面逐项按产品源码的数画，住在 `../apps/`。示意图与真机是两种东西，
不该住在同一层——判据不同，改的理由也不同。

## 成员清单

- **agents-reel.tsx**: 一镜到底。镜头开在侧栏**左上角**，自上而下摇到底，让
  每一行行首那枚 agent logo 一个一个走过镜头，然后停住（对话区骨架屏）。
  要讲的是「谁在干这活，看一眼行首就知道」，所以镜头必须停在行首那一列——
  也所以第一眼就得是那一列。画框 580×360，与左栏文字等高。
  **全站唯一一支带脚本的 reel**：十来行 IntersectionObserver 把「首帧」
  从时间轴的 0% 赎回给观众的第一眼，理由见文件头部。

## 共用的约定

- **定宽而非吃满**：`.reel` 那条规则只管圆角、桌面底色、定宽居中、溢出裁掉。
  580×360 是从左栏文字量出来的（那块文字恒是 359px 高）。镜头那四个数按 580 算，
  栏一浮动它们就全不作数；堆叠时居中，窄到定宽以下才退回 100%。
- **底色是桌面色**（`--ground-2`）而不是机器色，机身自带一圈边与影。两者同色
  时读起来是「一台机器浮在白里」，画框与机身分不出边界。
- **动作是 CSS keyframes**，形状全部服务端渲染。脚本只用在起播时机上——
  它不循环，所以「什么时候开始」成了一个必须回答的问题，
  而纯 CSS 回答不了「等被看见」。
- **不写 `will-change`**：那会把图层钉成固定分辨率的位图，推近之后字就糊了。
- **`prefers-reduced-motion` 下停**在能把话说完的那一格（侧栏左上角）——
  留下的该是这一节要说的话，而不是一张什么都看不清的全景。
  那一格就是 keyframes 的 0%，于是关掉动效、脚本没跑、等着起播
  三处看到的是同一帧。
- **它是首屏那台机器的缩影，缩放比只有一个数：0.75**（行高 32→24、
  行首槽 16→12、字标行 48→36、字标 26→20）。缩影里冒出第二个比例，
  就等于说这是另一台机器。
- 样式都住在 `app/globals.css` 的第 4 节，数据都住在 `@/lib/agents`。
  这一层只负责形状。
