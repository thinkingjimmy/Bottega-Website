# reels/

> L2 | 父级: ../../README.md

正文里两台会动的图。它们不是首屏那台机器的复制品（那台在 `../window/`，
几何逐项抄真组件）——这两台是**示意图**：只保留能把一句话说完的那几笔，
其余一律骨架条。判据是同一条：**这一节要讲的话，能不能由这个动作本身说出口。**

## 成员清单

- **agents-reel.tsx**: 一镜到底。先给整台机器（对话区骨架屏），推近到侧栏的
  左上角，再自上而下摇下去，让每一行行首那枚 agent logo 一个一个走过镜头。
  要讲的是「谁在干这活，看一眼行首就知道」，所以镜头必须停在行首那一列。
- **apps-reel.tsx**: 四张幻灯。同一台窗口里轮播四只 App 的表面——画布、看板、
  账本、热力图。要讲的是「App 是为这件事长出来的一张面孔」，而四张长得都
  不一样正是这句话唯一的证据；写四行文案说「它们各不相同」，不如把四张摆出来。

## 共用的约定

- **画框定宽 540px**（`.reel` / `.apps-reel` 共用那条规则）。镜头的七个数与
  幻灯的错位都按这个宽度算，栏一浮动它们就全不作数；堆叠时居中，窄到 540
  以下才退回 100%。
- **底色是桌面色**（`--ground-2`）而不是机器色，机身自带一圈边与影。两者同色
  时读起来是「一台机器浮在白里」，画框与机身分不出边界。
- **无 hook、无脚本**：两段都是纯 CSS keyframes，服务端渲染即可。
- **不写 `will-change`**：那会把图层钉成固定分辨率的位图，推近之后字就糊了。
- **`prefers-reduced-motion` 下都停**，各自停在能把话说完的那一格（agents 停在
  推近侧栏，apps 停在第一张）——留下的该是这一节要说的话，而不是一张全景，
  或者四张叠在一起。
- 样式都住在 `app/globals.css` 的第 4 节，数据都住在 `@/lib/agents`。
  这一层只负责形状。
