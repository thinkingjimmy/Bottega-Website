## Members

- `site.ts`: Defines the production origin, social image dimensions, and absolute URL builder used by pages and build audits.
- `structured-data.ts`: Describes the localized page, website, currently downloadable desktop platforms, exact release page, and real breadcrumb destinations as JSON-LD.

The production origin follows the deployed redirect destination, `https://www.getbottega.app`.
Page titles and descriptions come from the same localized inputs as the HTML metadata.
Software version, available platforms and download destination come from the release snapshot; missing installers never appear as downloadable operating systems. Ratings and reviews require published evidence.
