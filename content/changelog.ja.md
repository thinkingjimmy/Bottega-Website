# 変更履歴

このファイルは内部実装の反復ではなく、製品のマイルストーンを記録します。


## 2026-10-07 — v0.2.2

[0.2.2 をダウンロード](https://github.com/thinkingjimmy/Bottega/releases/tag/v0.2.2)。Apple シリコン搭載の Mac 向けです。[Bottega Web](https://app.getbottega.app) も利用できます。

- **端末間で一貫した会話。** デスクトップと Web で会話表示、入力欄の操作、既読状態を共有します。Chat を読むと、実行するコンピューターと接続済みの画面にも既読状態が反映されます。 質問や Plan の確認中も停止でき、待機中のコマンドには復旧操作が残ります。 同期中に生成された応答は、復旧後も保持されます。
- **送信前に Project のブランチを選択。** New Chat からブランチを検索、切り替え、作成できます。リモート操作は選択したコンピューターで実行します。Project 設定から戻っても、添付、参照、Plan、権限、モデルを含む下書きが残ります。処理中の Project や Git の競合は、切り替える前に解決します。
- **設定と操作を統一。** Agent 選択、サイドバー、設定レイアウトを揃えました。Skills の空の一覧は Extensions と同じ構成です。プラグインはデスクトップでインストールします。 紹介から一覧に戻れます。ツール設定にはプラグインと管理対象 Preview の操作を含みます。
- **インストール版のスケッチを修正。** パッケージ内のリソースから隔離エディターを初期化し、編集可能な内容と共有メニューの状態を保ちます。 確認済み App のインストールは、承認したパッケージを変更せずに復旧できます。

Cloud Sync は **プロトコル 15** に更新します。クラウド機能を使うすべてのデスクトップを更新してください。旧プロトコル 14 のクライアントは、更新後に再接続できます。既存のクラウド内容、同期パスワード、アカウント鍵は保持します。Bottega を完全に終了してアプリを手動で置き換えてください。このプレリリースは ad-hoc 署名を使用し、Apple の公証を受けていません。GitHub Latest の対象外です。

## 2026-10-06 — v0.2.1

macOS Apple シリコンと Web。プロトコル 14、クラウドの内容、同期パスワードを維持します。0.2.0 からは終了後にアプリを手動で置き換えてください。ad-hoc 署名で Apple の公証はありません。GitHub Latest に含まれないプレリリースです。アイドル時 CPU、実機確認、正式署名は引き続き確認中です。

- **初回起動を短く。** 内容フォルダと Agent を選ぶだけで開始できます。Skills と Memory は後から設定できます。壊れた PATH の入口に妨げられず、macOS の Codex アプリ内の CLI も検出します。
- **必要なときだけ履歴を取り込む。** Project 設定から、インストール済み Agent の履歴だけを確認して取り込みます。初回追加後や再起動時の自動走査はありません。
- **Agent の選択を維持。** 設定した好みと最初のメッセージのモデルを、モデル一覧更新中も保持します。入力メニューと Project 設定の配置、タブ切り替えを整理しました。
- **Memory の操作を一致。** プラグインの表示とサービスの許可を別々に制御し、保存したサービス選択とデータを保持して必要な同意を確認します。
- **Sketch を確実に復旧。** ネイティブコンパイラーや初期化の失敗から再試行でき、確定したスケッチを保持します。
- **同期とログインを明確に。** 同期パスワードの注意を一度説明し、承認前に要求元のコンピューター、アカウント、コードを確認します。同期未接続の入力欄には復旧方法を表示します。

## 2026-10-04 — v0.2.0

macOS Apple シリコンと Web のプレリリースです。手動更新、ad-hoc 署名、公証なし。Windows、Linux、Android の配布は別途予定します。プロトコル 14 のため、クラウドを使うプロトコル 13 のデスクトップは更新が必要です。既存のクラウド内容と同期パスワードを保持します。終了して内容とアプリケーションデータをバックアップしてください。正式署名と詳細な実機確認は継続中です。

- **プラグインを一か所に。** 設定で機能、依存関係、入手元、利用状況を確認できます。Base、Providers、Workflow、Sketch、Memory、Dock は共通の操作を使い、無効にしても内容を保持します。
- **Agent 設定とワークフロー。** モデルと推論レベルを一覧から選び、読み込み失敗時は編集を保持して再試行できます。Skills、MCP、Memory の許可を明示し、検証済みの四つの Agent が工程を実行できます。計画とレビューは読み取り専用です。
- **編集可能な Sketch プラグイン。** 画像と編集用ソースを保持し、版を切り替えられます。ビルド失敗時は動作する旧版を維持し、再起動と更新でも確定内容や未保存の編集を保護します。
- **Memory を明示的に制御。** 初期状態は無効です。Web から所有コンピューターへ一時停止や再開を要求し、反映状態を確認できます。ワークフローの Memory は別許可の読み取り専用で、新しい記憶を収集しません。
- **選んだ画面に Dock。** 主画面、外部画面、指定画面の左・下・右に配置できます。配置はコンピューターごと、レイアウトは同期可能です。この版はシステム Dock との共存を提供し、置き換えは利用できません。
- **Web の作業場を充実。** App と Base のメニューは狭い画面に対応し、オフライン理由や工程の報告・証跡を表示します。通知を選べ、静的 App と Base を使う App が開けます。server App の画面はデスクトップ限定です。
- **復旧方法を明確に。** フォルダと起動の失敗に具体的な操作を表示し、終了は下書き保存を待ちます。読み込みやコンパイルの失敗は編集・次回起動を保護し、更新はローカル編集を維持します。履歴更新は保存済み Chat を保持します。

## 2026-09-30 — v0.1.9

更新前に Bottega フォルダとアプリケーションデータをバックアップしてください。0.1.8 のデータベースはそのまま隔離し、会話索引をフォルダから再構築します。この版ではクラウドをリセットしたため再ログインし、最初のコンピューターで同期パスワードを設定します。プロトコル 13。配布は未署名・未公証の macOS Apple シリコン DMG/ZIP のみです。0.1.0 と 0.1.1 からは手動更新が必要です。

- **Plan・Develop・Review。** Project の Base 行からワークフローを開始し、計画の確認、結果の承認・例外承認・差し戻し、一時停止、取消、再試行を行えます。Stage と受入条件を追加し、確認待ちを通知します。この版は Claude と Codex に対応します。
- **再利用できる Agent 設定。** Provider、モデル、指示、権限、作業領域、ネットワークを保存して同期できます。Blank、Planner、Developer、Reviewer から開始し、変更は以後の実行に適用します。
- **Plugins と Apps。** Base、四つの Providers、Workflow、Extensions、各 Agent のプラグインを一か所で管理します。無効化でデータは削除しません。
- **Web とスマートフォンの Needs you。** 実行開始、確認、承認、差し戻し、一時停止、取消を行えます。ベルが確認待ちを一覧にし、静的 App と Base を使う App の画面も開けます。
- **Node を同梱。** 内蔵 MCP、App コンパイラー、Agent アダプター、App の Node スクリプトは、PATH ではなく同梱 Node 24 を使います。
- **Agent の境界を強化。** GitHub CLI 設定へのアクセスを防ぎ、レビューで権限を増やしません。ブラウザ操作を選択したタブに制限し、Codex の確認・自動承認・計画モードは Bottega のサンドボックスを使います。
- **会話を安定化。** 下書きは終了・クラッシュ・再起動後も残り、非表示 Chat の待機メッセージも送信します。起動中の送信を待機し、ファイル保存失敗は再試行かスキップを選べます。
- **コードでログインを確認。** Web でデスクトップのログインを承認するとき、要求元の画面に表示されたコードを選びます。
- **設定と復旧を整理。** Lab と接続保持を削除し、Development Kanban の同梱を終了しました。既存のインストールは維持します。失われた Bottega フォルダは復旧画面で選択し直せます。
- **プロトコル 13。** Agent 設定、ワークフロー列、実行と Needs you の情報を同期します。

## 2026-09-24 — v0.1.8

0.1.7 のローカルデータと設定、クラウド内容を維持します。プロトコル 10 のため、同じアカウントの全コンピューターを更新してください。この版は未署名・未公証の macOS arm64、Windows x64、Linux x64 インストーラーを提供します。macOS が主対象で、他の環境の機能差は継続対応です。

- **Bottega Dock。** macOS 15 以降の Apple シリコンで App、Finder、Downloads、Trash、Agent 使用量を表示します。この版では共存または置き換えを選べ、異常終了時の復旧項目と Restore System Dock を用意します。
- **Dock レイアウトを同期。** アカウントのコンピューター間で端末間暗号化して同期します。同時編集は可能な部分を統合し、残りを確認します。
- **設定を統一。** Dock、Sync、Memory の区画と行、進捗、失敗表示を揃え、設定手順は同じダイアログを使います。初回設定には左側の手順一覧を追加しました。
- **Bottega フォルダを移動。** 再起動時に保存先と参照を変更します。別ディスクでは全内容をコピーして検証した後、元のコピーを Trash に移します。
- **このコンピューターのデータを消去。** 会話、設定、鍵、ログインを消して初回設定へ戻れます。フォルダも Trash に移せますが、クラウドは保持し、再ログイン後に取得できます。
- **削除されたフォルダから再設定。** 起動を止めずに設定へ戻ります。読めない会話コピーはフォルダの .trash に移し、一度通知します。
- **プロトコル 10。** 暗号化した Dock レイアウトを同期します。ローカルデータは変更しません。

## 2026-09-23 — v0.1.7

0.1.6 のローカルデータ、クラウド内容、同期パスワードを維持します。プロトコル 9 のため、全コンピューターを更新してください。未署名・未公証の macOS arm64、Windows x64、Linux x64 を提供し、macOS 以外の完全な機能対応は継続中です。

- **Providers・Updates・Community。** 新しい Chat の Agent と表示順、各 CLI と Bottega の更新、GitHub とリリース情報を管理します。Update all は CLI を先に更新します。About と Backends を統合しました。
- **受け取れない指示を待機。** 実行中に追加したメッセージを対応 Agent はその回で使い、Kimi と OpenCode は終了後に送信します。拒否時も下書きを保持し、終了済みなら新しいメッセージとして送れます。
- **送信前に添付を整理。** 遠隔送信の写真は最大 2048 px に縮小し、位置・機器情報などのメタデータを除去します。実形式を検査し、HEIC の非対応を説明します。20 時間経過した未送信アップロードは再アップロードを案内します。

- **オフライン時間を表示。** 入力欄でコンピューターの休眠、オフライン、切断と最終確認からの時間を示します。
- **プロトコル 9。** 追加指示の処理結果と将来のモバイル対応を準備します。ローカルデータは変更しません。

## 2026-09-22 — v0.1.6

更新前に終了し、Bottega フォルダとアプリケーションデータをバックアップしてください。0.1.5 のデータベースと付随ファイルを原形のまま隔離し、索引をフォルダから再構築します。未完の返信が失われる場合があり、検索・同期状態を作り直します。この版のクラウドはリセットされるため再ログインと最初のコンピューターでのパスワード設定が必要です。

- **会話は作成したコンピューターに所属。** 実行中の会話を別のコンピューターへ移さず、所有コンピューターを開いて操作します。実行者選択、引き継ぎ、コンピューター間の待機列を削除しました。
- **ログインが遠隔操作。** ログインしたコンピューターは Projects と Chats を公開し、その操作を受けます。別のスイッチはありません。初回はローカルで開始し、ログイン時に同期パスワードを設定・入力します。
- **サイドバーでコンピューターを切り替え。** Web、スマートフォン、デスクトップの共通タブに状態と経過時間を表示します。重複名を区別し、コンピューターのないアカウントには最初のログインを案内します。
- **遠隔 Project を使う。** 所有コンピューター名と地球マークを表示し、ローカルのフォルダは要求しません。そこに作る Chat は所有者側で動作・保存します。ピン留めはコピーせず、解除は所有者を変更しません。
- **オフラインでも記録を編集。** 改名、アーカイブ、並べ替え、Base や App の記録は編集でき、復帰後に照合します。送信・停止・承認など実行には接続が必要です。重複承認は処理したコンピューターを示します。
- **フォルダは所有コンピューターに所属。** 同じコンピューターは再インストール後も再取得でき、別のコンピューターは所有者名と対応方法を表示して拒否します。未同期のフォルダはどこでも開けます。
- **取り込んだ会話を継続。** Codex、Claude Code、Kimi の履歴を新しい profile や再構築後も通常の入力欄で続けられます。履歴との境界を一つの区切りで示します。
- **初回アップロードを正確に。** 実際のバイト数と総量を表示し、小さな会話から開始します。各メッセージの往復回数を約半分にしました。
- **プロトコル 8。** 同期プロトコルとローカルデータベースを更新しました。上記のバックアップと復旧手順を確認してください。

## 2026-09-19 — v0.1.5

新しい Bottega フォルダ中心の保存形式です。0.1.4 以前の Chat、Project、App、Base、添付、設定を自動移行しません。終了し、アプリケーションデータ全体と外部 Chat Home・Project を保持してから、古いデータをバックアップ場所へ移し、新しいフォルダで設定してください。元の内容は変更しません。

- **端末間暗号化の Cloud Sync。** 任意で有効化し、最初のコンピューターで別の同期パスワードを設定します。端末で鍵を作り、暗号文だけを保存します。復旧鍵やパスワード再設定はありません。同じアカウントとパスワードで参加します。
- **ブラウザで作業場を開く。** Chat、添付、直近七日間の本文検索、Base の六つの表示、同期した App の記録、アーカイブ、端末と設定を扱えます。スマートフォンにも対応します。カスタム App 画面とローカルツールはコンピューター上に残ります。
- **別の端末から会話を継続。** サービスの遠隔操作が有効なら、オンラインでロック解除済みのコンピューターへ送信・停止・承認・追加指示できます。無効時も読み取りと実行中の表示は使えます。
- **自分のフォルダに保存。** 会話、添付、成果物、Chat Home、Project、Base、App ソース、Skills を保持します。鍵と端末権限はローカルです。完全バックアップは終了後にコピーし、iCloud や Dropbox の同期フォルダは使わないでください。
- **必要な初回設定。** この版のウィザードはローカル利用か既存アカウントを選び、フォルダ、Agents、Skills、Memory を案内します。
- **成果物を確認。** 可視化、ファイルのプレビュー・保存・表示、Quick Look、表の Base 取り込み、Claude の成果物表示を追加しました。プレビューはネットワークと保存にアクセスできません。
- **四つの Agent を制御。** OpenCode Go の使用量を追加し、タイトル生成の Agent とモデルを指定できます。Lab の接続保持は初期状態で無効です。
- **日常のサイドバー操作。** Chat のドラッグ順を同期し、Project を改名・並べ替えられます。アーカイブ時の紙吹雪は設定で無効にでき、動きを減らす設定にも従います。

## 2026-09-02 — v0.1.0

- 最初のインストーラーを公開しました。Bottega は GitHub Releases から macOS arm64 の DMG と ZIP、Windows x64 の NSIS インストーラー、Linux x64 の AppImage として入手できます。いずれもこの tag のコミットからビルドされています。これらのビルドは署名されていないため、初回起動時に各プラットフォームが求める一度きりの操作は getting-started ガイドに記載しています。
- Chat ストアを SQLite 上に作り直し、それを唯一の真実の源にしました。会話、turn、添付、fact が Chat ごとのファイルではなく一つの永続ローカルデータベースに収まり、Chat はクラッシュを越えて残り、再スキャンなしで再開し、長くなっても遅くなりません。
- 長い会話を開くコストを一定にしました。タイムライン、Chat アウトライン、Chat 内検索はすべてページングされ、数万 turn の Chat を開くコストは短い Chat と同じで、遡ってもトランスクリプト全体を読み直しません。
- gram ベースの全文検索を追加しました。中国語・日本語・韓国語のテキストも空白区切りの言語と同じ確実さで一致し、結果はトランスクリプトが読むのと同じストアから返ります。
- 取り込んだ履歴を一つのタイムラインに統合しました。ローカルの Codex、Claude Code、Kimi Code、OpenCode CLI から引き継いだ session が、独立した読み取り専用ビューではなく、Bottega で作成した Chat と同じトランスクリプト、アウトライン、検索、ナビゲーションで表示されます。
- fact の書き込みを狭めました。turn は自分が実際に所有する fact だけを更新するため、並行する turn、Memory の配信、Base の書き込みが互いの状態を上書きしなくなりました。
- マージレビューで見つかった問題を解消しました。App Use は completed の受領後にのみ遷移するため、拒否または復旧中の App がウィンドウを動かすことはありません。App の Base アクセス取り消しは一つの原子的な操作になり、アクセス権とライフサイクルが食い違わなくなりました。App と Project のピン留め、Project の外観、Settings のナビゲーションを整理し、サイドバーは常に実際に開いているものを反映します。
